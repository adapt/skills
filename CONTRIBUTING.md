# Contributing

For a skill change, share a sanitized reproduction, expected and actual
behavior, and results from a separate test input. Keep the change scoped and
state its dependencies and limits. Open an issue before proposing a new skill.

Check discovery with `npx skills add . --list` before submitting. CI also
verifies installation in Claude Code and Codex. Include only material you
have permission to share and license. Keep credentials and private task data
out of issues and pull requests.
